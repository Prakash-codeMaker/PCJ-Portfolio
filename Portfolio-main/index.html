An AI-assisted payment recovery workflow for ambiguous failed-payment cases.

Designed as a persistent case pipeline: report → evidence → verify → investigate → recovery route → approval → external action → monitor → resolve. AI interprets and extracts evidence; deterministic workflow state controls consequential actions; humans approve high-risk changes.
